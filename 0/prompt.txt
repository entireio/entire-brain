<result>## Force-sweep regression fixed (Bugbot, PR #590) — all gates green, not committed

### What changed (`internal/cli/distill_cmd.go`)
- **Pre-drop removed.** `ensureStore` no longer deletes distilled active facts up front; a force run holds the full corpus in memory for its whole duration, so a scoped or interrupted run can no longer lose anything it did not re-derive.
- **Final-flush scoped sweep replaces it.** New `sweepStaleForceFacts` runs only on the final flush, after `rebaseFactsOntoDisk`, only under `--force`. It drops a record iff it is distilled, active, not in `regeneratedFactIDs`, cites at least one provenance session id, and every cited id was fully rebuilt this run. Authored, retired, zero-session-provenance, and any fact citing an unrebuilt session survive.
- **Tracking.** `rebuiltSessionCount`/`sessionExportCount` count per session id across duplicate exports — a session counts as rebuilt only when every export of that id was fully distilled (no failed chunks). `regeneratedFactIDs` collects extraction upserts plus every record `reconcileStagedCandidates` created or changed (so a merge target absorbing this run's candidate is protected).
