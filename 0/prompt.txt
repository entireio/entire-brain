One goroutine blocks on an OS event: kqueue EVFILT_PROC/NOTE_EXIT on darwin, pidfd_open + poll on linux (PDEATHSIG fallback for old kernels), WaitForSingleObject on a parent handle on windows. On fire: one stderr line, os.Exit(1). No timers.
A register-then-recheck step closes the race where the parent dies before the watcher is in place.
Arming rules so it never kills a legitimate daemon: skip when initial ppid is 1 (launchd watcher), and skip detached children via an ENTIRE_BRAIN_DETACHED=1 env var set in spawnDetached — the setup backfill uses Setsid and must outlive its spawner, so this trap is called out explicitly.
Immediate exit is safe: writes are atomic renames and flock releases on process exit.
