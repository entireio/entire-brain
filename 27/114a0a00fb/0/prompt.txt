## Comment 3
File: /Users/thomi/Projects/entire-brain/internal/cli/retrieve_cmd.go
Side: R
Lines: 186-193
Comment:
[P1] Do not promote retrieved prose into decisive edits

All retrieved docs and history are copied into History.Matches. The downstream Historical assignments parser trusts a marker in that prose, associates assignments with any likely file containing the same name, chooses a lexical test, and can mark it complete_on_pass. A stale or malicious document can therefore manufacture an exact edit instruction. Assignments need structured provenance tied to the original file and revision, and unverified prose must never produce a decisive action.

Comment:
[P2] Keep indexed retrieval off the live source tree

Every search/query of at least eight characters invokes a repository scan that reads up to 2,500 source files of up to 512 KiB each; likely-file generation can perform another scan.
